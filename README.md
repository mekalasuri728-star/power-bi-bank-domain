# power-bi-bank-domain

 Tools Used:
Power BI

📌 Project Overview
This project focuses on performing end-to-end data analysis in the banking domain, involving customer behavior and engagement insights.Dashboard creation using Power BI.

🗃️ Dataset
Contains anonymized customer data with features like:

-Demographics (Age, Gender, Nationality, Occupation)

2.Banking products (Deposits, Loans, Credit Cards, etc.)

3.Income, Loyalty Classification, Risk Weighting

Built interactive dashboards in Power BI to visualize KPIs like:

📊 Sample KPIs & Metrics

1.Engagement Count

2.Superannuation & Deposits Trends

3.Loyalty Classification Distribution

4.Foreign Currency Account Usage by Income Group


🎯 Business Insights

1.Customers with higher bank deposits often hold multiple account types.

2.Risk-weighted customers need monitoring for lending products.

3.Cross-sell opportunities identified among low-engagement customers.
